# Portal CCP — CSS personalizado

Este repositório contém o CSS personalizado do Portal do Conselho das Comunidades Portuguesas (CCP).

O portal utiliza WordPress, o tema Vantage e o SiteOrigin Page Builder. O arquivo [`css/ccp.css`](css/ccp.css) é a fonte oficial e deve ser posteriormente aplicado ao recurso de CSS personalizado/adicional do WordPress.

O WordPress completo, temas, plugins, uploads e banco de dados não fazem parte deste repositório.
